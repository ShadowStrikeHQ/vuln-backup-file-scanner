# vuln-Backup-File-Scanner
Scans a website for common backup file extensions (e.g., .bak, .old, .swp) to identify potential information leakage. - Focused on Assess vulnerabilities in web applications by performing scans and providing detailed reports

## Install
`git clone https://github.com/ShadowStrikeHQ/vuln-backup-file-scanner`

## Usage
`./vuln-backup-file-scanner [params]`

## Parameters
- `-h`: Show help message and exit
- `-o`: No description provided
- `-v`: No description provided
